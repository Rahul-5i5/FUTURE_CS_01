# FUTURE_CS_01

## Vulnerability Assessment Report

This repository contains Task 1 submission for the Cyber Security Internship at Future Interns.

## Objective

To perform a basic vulnerability assessment on a web application using Nmap and OWASP ZAP.

## Tools Used

* Nmap
* OWASP ZAP
* Browser DevTools

## Activities Performed

* Network reconnaissance
* Port scanning
* Passive vulnerability analysis
* Risk classification
* Security recommendations

## Deliverables

* Vulnerability Assessment Report
* Nmap Scan Results
* OWASP ZAP Findings
* Screenshots

## Outcome

Identified multiple low and medium-risk security issues and provided remediation recommendations.
